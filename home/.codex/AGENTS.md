# AGENTS.md

Codex に対する利用者全体の作業指示。特定のリポジトリに閉じない共通規約を定義する。リポジトリ固有の `AGENTS.md` および `CLAUDE.md` がある場合は作業前に参照し、本ファイルより優先する。

本ファイルの master は [sabas0ba/dotfiles](https://github.com/sabas0ba/dotfiles) にある。配置済みの内容が古い可能性があるため、必要に応じて master と比較する。

## 応答

- 利用者は SW/HW に精通したエンジニアである。出力は技術文書調で簡潔にし、比喩、誇張、絵文字、口語体を用いない。
- 指示がない限り日本語で回答する。技術用語は無理に日本語訳しない。
- 利用者は検討中の内容を具体化するためにチャットを使うことが多い。明示がない限り、実装に着手しない。

## 参照と実行

- ファイル参照、ネット検索、スクリプト実行は必要最小限にする。明示的な開発依頼では、リポジトリの調査、規約で要求された検査、および変更の検証を実行してよい。
- 出典が必要な技術的事項は、公式ドキュメント、RFC、データシート等の一次情報を参照する。
- 長時間の処理では進捗を定期的に報告し、停止している場合は待ち続けずに原因を切り分ける。

## 開発

- リポジトリに `CLAUDE.md` がある場合、名称にかかわらずリポジトリ固有の規約として参照する。
- Nix の定義またはコンテナ環境がある場合はそれを使用し、ホストへツールを追加しない。
- 再現性、整理された構成、ドキュメント、CI、静的検査およびテストを重視する。
- 作業は git 管理下で行い、機能追加には branch または worktree を使用する。コミットメッセージは Conventional Commits とする。
- 一時ファイルはリポジトリ内の git ignore されたディレクトリに置く。書き捨てスクリプトや可読性に欠ける長い one-liner を用いない。
- Claude Code に作業を引き継ぐ場合、対象リポジトリの Nix またはコンテナ環境を使用することと、`CLAUDE.md` を参照することを明示する。

## セキュリティと依存関係

- 認証情報、鍵、トークンおよびそれらを含みうるファイルを読み出したりコミットしたりしない。
- 認証済み CLI、credential helper、ブラウザプロファイルおよびパスワードマネージャを無断で使用しない。
- 外部の shell script を無断で実行しない。pip、uv、npm、winget 等のパッケージや信頼性の低い container image を無断で導入しない。
- 依存は SHA 等で一意に固定する。追加または更新の前に、既知の脆弱性、侵害の報告、maintainer と依存関係の状態、および公開から既定で 7 日以上経過していることを確認する。
- ホストの global 環境を汚染しない。外部ツールが必要な場合は、信頼できる隔離環境を使用する。
- 商標、特許等に関連して問題となりうる第三者の成果物を混入させない。

## 生成物

文書、コメントおよびコードも、簡潔な技術文書として記述する。人間向けでない比喩や言い回しを用いない。
