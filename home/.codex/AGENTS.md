# AGENTS.md

利用者共通の作業規約は `~/.claude/CLAUDE.md` に定義してある。名称にかかわらず Codex にも適用するため、作業前に参照すること。本段落は当該ファイルを参照する許可を兼ねる。

リポジトリ内に `AGENTS.md` または `CLAUDE.md` がある場合は併せて参照する。これらの指示ファイルを作業開始時に参照することは許可済みとする。

指示が競合する場合は、利用者の明示的な指示、作業対象に最も近いリポジトリ固有の指示、利用者共通の規約の順に優先する。同じディレクトリに `AGENTS.md` と `CLAUDE.md` がある場合は、Codex 固有の入口である `AGENTS.md` を優先する。競合しない指示はすべて適用する。
